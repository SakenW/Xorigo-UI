# Getting Started

Welcome to Xorigo UI! This guide will help you get started with our component library.

## Installation

```bash
npm install @xorigo-ui/core
```

## Basic Usage

```tsx
import { Button, Card } from '@xorigo-ui/core'

function App() {
  return (
    <Card>
      <Button variant="primary">Click me</Button>
    </Card>
  )
}
```
