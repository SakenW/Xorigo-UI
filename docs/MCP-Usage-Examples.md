## 💡 高级使用技巧

### 1. 多 MCP 链式调用
```
用户: "搜索 → 分析 → 创建 → 测试 → 保存"

实际执行:
Tavily 搜索 → Sequential 分析 → Magic 创建 → ESLint 检查 → Memory 保存
```

### 2. 条件化使用
```
如果 (Tavily 搜索结果质量高) {
    使用 Sequential 进行深度分析
} 否则 {
    使用 Context7 查询官方文档
}
```

### 3. 错误恢复
```
如果 (Magic 生成失败) {
    回退到手动编码 + ESLint 检查
    用 Memory 记录失败原因
}
```
