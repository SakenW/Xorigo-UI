# Xorigo UI 首页版本使用指南

## 📋 版本概览

Xorigo UI 首页重构已完成，提供了4种不同风格的首页设计，每种都充分利用了 React 19 和 Framer Motion 12 的强大功能。

## 🎯 访问方式

### 1. **主选择器页面** (推荐)
```
http://localhost:3100/demo
```
- 查看所有4个版本的预览
- 点击卡片选择要查看的版本
- 包含详细的功能说明

### 2. **版本对比页面** (新功能)
```
http://localhost:3100/demo-compare
```
- 直接在终极稳定版和终极增强版之间切换
- 顶部按钮快速切换
- 右下角浮动按钮快速跳转

### 3. **直接访问方式**

#### **推荐版本**
- **终极稳定版**: `http://localhost:3100/demo` → 点击"终极稳定版"卡片
  - ✅ 性能优化，流畅运行
  - ✅ 核心功能完整
  - ✅ 无JavaScript错误

#### **实验版本**
- **终极增强版**: 通过对比页面访问
  - ⚠️ 功能完整但可能有动画错误
  - 🎨 包含所有高级动效
  - 🔧 实验性功能展示

## 🚀 使用建议

### **首次访问**
1. 访问 `http://localhost:3100/demo`
2. 浏览所有版本特色
3. 选择最适合的版本

### **日常使用**
- 推荐 **终极稳定版**，功能完整且性能稳定

### **功能体验**
- 通过 **对比页面** (`/demo-compare`) 体验不同版本
- 可以实时切换对比效果

## ⚠️ 注意事项

1. **Docker环境**: 确保Docker容器正在运行
   ```bash
   docker ps | grep xorigo
   ```

2. **端口访问**: 使用端口 3100 而非 3000
   ```bash
   http://localhost:3100
   ```

3. **动画错误**: 如果遇到JavaScript错误，刷新页面或切换到稳定版本

4. **性能考虑**: 终极增强版包含大量动画，建议在性能较好的设备上体验

## 🛠️ 故障排除

### **404错误**
- 确保Docker容器正在运行
- 检查端口3100是否被占用
- 重启Docker容器: `docker restart xorigo-ui-website-dev`

### **动画错误**
- 刷新页面
- 切换到稳定版本
- 检查浏览器控制台错误信息

### **性能问题**
- 关闭浏览器其他标签页
- 切换到稳定版本
- 检查系统资源使用情况
