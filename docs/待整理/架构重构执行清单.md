## 📊 当前架构现状分析

### 现有 packages 结构
```
packages/
├── core/                          # 核心组件库（需要重构）
│   ├── src/
│   │   ├── components/           # 组件目录（需要重组）
│   │   │   ├── ui/               # → 需迁移到 base/
│   │   │   ├── feedback/         # → 需迁移到 feedback/
│   │   │   ├── navigation/       # → 需与 navigation/ 合并
│   │   │   ├── advanced/         # → 需拆分到 data/ 或 composite/
│   │   │   └── radix/            # → 需迁移到 adapters/radix/
│   │   ├── blocks/               # → 需迁移到 composite/
│   │   ├── hooks/                # → 需抽离到独立包 @xorigo-ui/hooks
│   │   ├── theme/                # → 需抽离到独立包 @xorigo-ui/system
│   │   ├── layouts/              # 空目录（待实现）
│   │   ├── types/                # 保留
│   │   └── utils/                # 保留
├── tokens/                        # ✅ 设计令牌（保持现状）
├── style-recipe/                  # ✅ 样式配方（保持现状）
├── i18n/                         # ✅ 国际化（保持现状）
└── registry/                      # ✅ 组件注册（保持现状）
```

### 目标架构
```
packages/
├── core/                          # 九大类组件重组后
│   ├── src/
│   │   ├── base/                 # 原子层元素（原 components/ui）
```
