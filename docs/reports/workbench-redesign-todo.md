## 🔧 开发规范

### Git 工作流
- 主分支: `main`
- 开发分支: `feature/workbench-2.0`
- 发布分支: `release/v2.0.0`

### 代码规范
- TypeScript 严格模式
- ESLint + Prettier 自动化
- 组件命名遵循 kebab-case
- 提交信息遵循 Conventional Commits

- 单元测试: Vitest + Testing Library
- E2E 测试: Playwright
- 性能测试: Lighthouse CI
- 可访问性测试: axe-core
