## 🛠️ 配置优化

### coverage 配置对比

**升级前**:
```typescript
// 使用外部 @vitest/coverage-v8
test: {
  globals: true,
  environment: 'jsdom',
  // 缺少覆盖率配置
}
```

**升级后**:
```typescript
test: {
  globals: true,
  environment: 'jsdom',
  coverage: {
    provider: 'v8',              // 内置 v8 支持
    reporter: ['text', 'json', 'html'],  // 多格式报告
    exclude: [...],              // 完整排除规则
  },
}
```

### 关键改进
1. **内置覆盖率**: 不再依赖外部包
2. **多格式报告**: 支持文本、JSON、HTML
3. **灵活排除**: 精确控制覆盖范围
4. **性能优化**: 更快的覆盖率计算
