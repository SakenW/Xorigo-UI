### 1. 了解现状 (30分钟)
```bash
# 阅读快速总结
cat docs/reports/RESEARCH-SUMMARY.md | less

# 查看架构评分
grep "架构健康度" docs/reports/RESEARCH-SUMMARY.md
```

### 2. 执行前置检查 (1小时)
```bash
# 运行前置检查
cd apps/website
npm run type-check
npm run lint
npm run build
```

### 3. 开始重构 (立即)
```bash
# 创建重构分支
git checkout -b website-refactor-2025-10

# 初始化目录
mkdir -p apps/website/src/data
mkdir -p apps/website/scripts
mkdir -p apps/website/config

# 开始第一个任务: 数据适配层
touch apps/website/src/data/registry.readonly.ts
```
