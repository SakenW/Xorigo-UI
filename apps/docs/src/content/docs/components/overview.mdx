## 设计原则

### 1. 原子化设计

我们的组件遵循原子化设计原则：

- **原子 (Atoms)**：最基本的 UI 构建块，如 Button、Input
- **分子 (Molecules)**：原子的简单组合，如 SearchInput、FormField
- **生物体 (Organisms)**：复杂的组件组合，如 Header、DataTable

### 2. 一致性 API

所有组件都遵循一致的 API 设计：

```tsx
interface ComponentProps {
  variant?: 'primary' | 'secondary' | 'outline'  // 变体系统
  size?: 'sm' | 'md' | 'lg'                       // 尺寸系统
  className?: string                              // 样式扩展
  children?: React.ReactNode                      // 内容组合
  disabled?: boolean                              // 状态控制
}
```

### 3. 可访问性优先

- 内置 ARIA 属性支持
- 键盘导航友好
- 屏幕阅读器兼容
- 符合 WCAG 2.1 标准

### 4. 主题系统集成

- 使用 CSS 变量实现主题切换
- 支持 10 种内置主题
- 完全可定制的颜色系统
- 响应式设计支持

## 使用指南

### 按需导入

推荐使用按需导入来减少打包体积：

```tsx
// ✅ 推荐：按需导入
import { Button, Input } from '@xorigo-ui/core'

// ❌ 不推荐：全量导入
import * as XorigoUI from '@xorigo-ui/core'
```

### 组合使用

组件设计为可组合使用：

```tsx
import { Card, CardHeader, CardContent, CardFooter, Button, Input } from '@xorigo-ui/core'

function LoginForm() {
  return (
    <Card className="w-96">
      <CardHeader>
        <h2>登录</h2>
      </CardHeader>
      <CardContent className="space-y-4">
        <Input placeholder="用户名" />
        <Input type="password" placeholder="密码" />
      </CardContent>
      <CardFooter>
        <Button className="w-full">登录</Button>
      </CardFooter>
    </Card>
  )
}
```

### 主题定制

```tsx
import { ThemeProvider } from '@xorigo-ui/core'

function App() {
  return (
    <ThemeProvider theme="dark">
      <YourComponents />
    </ThemeProvider>
  )
}
```
