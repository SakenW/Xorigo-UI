设计令牌是设计系统的最小单位，定义了整个产品视觉语言的原子元素。Xorigo UI 提供了完整的设计令牌系统，支持主题定制和响应式设计。

## 令牌类型

## 令牌使用

### 在 CSS 中使用

```css
.my-component {
  /* 使用颜色令牌 */
  background-color: var(--color-primary-500);
  color: var(--color-text-primary);
  border-color: var(--color-border-light);

  /* 使用字体令牌 */
  font-family: var(--font-sans);
  font-size: var(--text-lg);
  font-weight: var(--font-medium);
  line-height: var(--leading-normal);

  /* 使用间距令牌 */
  padding: var(--space-4) var(--space-6);
  margin: var(--space-2) 0;

  /* 使用圆角令牌 */
  border-radius: var(--radius-lg);

  /* 使用阴影令牌 */
  box-shadow: var(--shadow-md);

  /* 使用过渡令牌 */
  transition: var(--transition-colors);
}
```

### 在 React 组件中使用

```tsx
import { cva } from 'class-variance-authority'

const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-md font-medium transition-colors',
  {
    variants: {
      variant: {
        primary: [
          'bg-blue-500',
          'text-white',
          'hover:bg-blue-600'
        ],
        secondary: [
          'bg-gray-100',
          'text-gray-900',
          'hover:bg-gray-200'
        ]
      },
      size: {
        sm: ['h-8', 'px-3', 'text-sm'],
        md: ['h-10', 'px-4', 'text-base'],
        lg: ['h-12', 'px-6', 'text-lg']
      }
    },
    defaultVariants: {
      variant: 'primary',
      size: 'md'
    }
  }
)

interface ButtonProps {
  variant?: 'primary' | 'secondary'
  size?: 'sm' | 'md' | 'lg'
  className?: string
}

export const Button = ({ variant, size, className, ...props }: ButtonProps) => (
  <button
    className={buttonVariants({ variant, size, className })}
    {...props}
  />
)
```

### 主题定制

```tsx
// 自定义主题
const customTheme = {
  colors: {
    primary: {
      50: '#f0f9ff',
      500: '#0ea5e9',  // 蓝色
      900: '#0c4a6e'
    },
    text: {
      primary: '#0f172a',
      secondary: '#64748b'
    }
  },
  spacing: {
    4: '1rem',    // 16px
    6: '1.5rem'   // 24px
  }
}

// 应用自定义主题
<ThemeProvider theme={customTheme}>
  <App />
</ThemeProvider>
```

## 响应式令牌

### 断点系统

```css
:root {
  --breakpoint-sm: 640px;
  --breakpoint-md: 768px;
  --breakpoint-lg: 1024px;
  --breakpoint-xl: 1280px;
  --breakpoint-2xl: 1536px;
}
```

### 响应式间距

```css
.responsive-component {
  /* 移动端 */
  padding: var(--space-2);

  /* 平板端 */
  @media (min-width: 768px) {
    padding: var(--space-4);
  }

  /* 桌面端 */
  @media (min-width: 1024px) {
    padding: var(--space-6);
  }
}
```

## 令牌扩展

### 添加自定义令牌

```css
:root {
  /* 自定义品牌色 */
  --color-brand-50: #fef2f2;
  --color-brand-500: #ef4444;
  --color-brand-900: #7f1d1d;

  /* 自定义动画 */
  --animation-bounce: bounce 1s infinite;
  --animation-spin: spin 1s linear infinite;

  /* 自定义渐变 */
  --gradient-primary: linear-gradient(135deg, var(--color-primary-500), var(--color-primary-600));
  --gradient-secondary: linear-gradient(135deg, var(--color-gray-100), var(--color-gray-200));
}
```

### 使用自定义令牌

```css
.brand-button {
  background: var(--color-brand-500);
  color: white;
  transition: var(--transition-fast);
}

.brand-button:hover {
  background: var(--color-brand-600);
  transform: translateY(-2px);
  box-shadow: var(--shadow-lg);
}

@keyframes bounce {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10px); }
}

@keyframes spin {
  from { transform: rotate(0deg); }
  to { transform: rotate(360deg); }
}
```

## 最佳实践

1. **一致性**: 始终使用设计令牌，避免硬编码值
2. **语义化**: 优先使用语义化令牌（如 `--color-text-primary`）而非原始令牌（如 `--color-gray-900`）
3. **可扩展性**: 设计令牌应该易于扩展和修改
4. **文档化**: 为自定义令牌提供清晰的文档
5. **测试**: 确保令牌在不同主题和设备上的一致性表现
