## 🚀 快速开始

### 安装

```bash
npm install @xorigo-ui/core
```

### 基础使用

```tsx
import { Button, Card, Input } from '@xorigo-ui/core'

function App() {
  return (
    <div className="p-4 space-y-4">
      <Card>
        <h1>欢迎使用 Xorigo UI</h1>
        <Input placeholder="输入内容..." />
        <Button variant="primary">提交</Button>
      </Card>
    </div>
  )
}
```

## 🎨 主题支持

Xorigo UI 支持多种内置主题，可以轻松切换应用的外观：

```tsx
import { ThemeProvider } from '@xorigo-ui/core'

// 使用深色主题
<ThemeProvider theme="dark">
  <App />
</ThemeProvider>

// 使用自定义主题
<ThemeProvider theme={{
  colors: {
    primary: '#3b82f6',
    secondary: '#64748b',
    // ...更多颜色配置
  }}>
  <App />
</ThemeProvider>
```
