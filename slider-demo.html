Xorigo UI Slider 组件

基于 React 19 + TypeScript 5.9 + Framer Motion 12 + Tailwind CSS 4 构建的现代化滑块组件。 提供完整的表单输入解决方案，支持单值和范围选择、垂直和水平方向、自定义标记点等功能。

🎉 组件已成功生成！

Slider 组件已按照 Xorigo UI v1.5.1 架构规范完成开发，包含完整的 TypeScript 类型定义、测试文件和 Storybook 故事。

主要特性

  • 单值和范围选择：支持单个数值或数值范围选择
  • 双向操作：支持垂直和水平方向
  • 标记点支持：可在滑块上显示自定义标记点
  • 实时数值显示：可选的数值标签和输入框
  • 主题集成：完整支持 Xorigo UI 七轴主题系统
  • 动画效果：三种动画变体（default、smooth、bounce）
  • 可访问性：完整的键盘导航和屏幕阅读器支持
  • TypeScript：完整的类型定义和类型安全

基础用法示例

// 单值滑块 <Slider value={50} min={0} max={100} label="音量控制" helperText="拖动滑块调整音量大小" /> // 范围滑块 <Slider value={[25, 75]} min={0} max={100} label="价格范围" helperText="选择价格区间" showInput formatValue={(val) => \`¥${val}\`} /> // 带标记点的垂直滑块 <Slider value={60} orientation="vertical" showMarks marks={[ { value: 0, label: '最小' }, { value: 50, label: '中间' }, { value: 100, label: '最大' } ]} label="进度设置" />

API 属性

  • value：滑块值（单值或范围值）
  • defaultValue：非受控模式的默认值
  • onValueChange：值变化回调函数
  • min / max：最小值和最大值
  • step：步长
  • orientation：方向（horizontal | vertical）
  • showMarks：是否显示标记点
  • showLabel：是否显示数值标签
  • showInput：是否显示输入框
  • variant：动画变体（default | smooth | bounce）
  • size：尺寸（sm | md | lg）
  • color：颜色主题（primary | secondary | success | warning | error）
  • formatValue：数值格式化函数
  • disabled：是否禁用

🎨 主题系统集成

Slider 组件完全集成 Xorigo UI 的七轴主题系统，支持：

  • 模式轴（Mode）：light/dark/auto 自动适配
  • 色调轴（Hue）：支持自定义色相
  • 饱和度轴（Saturation）：可调节色彩鲜艳度
  • 亮度轴（Lightness）：动态明暗程度
  • 密度轴（Density）：空间紧凑度适配
  • 圆度轴（Roundness）：边角圆润度变化
  • 对比度轴（Contrast）：视觉对比度支持
