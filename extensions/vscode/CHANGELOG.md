## [1.0.0] - 2025-11-05

### 新增
- ✨ 初始版本发布
- 🎯 智能代码补全系统
  - 组件名自动补全
  - 属性智能提示
  - 变体和尺寸选择
  - 状态值补全
- 📚 悬停文档系统
  - 组件详情展示
  - 属性列表查看
  - 使用示例代码
  - 分类信息提示
- 🎨 主题预览功能
  - 10+ 预置主题
  - 实时主题预览
  - 一键主题切换
  - 七轴主题系统支持
- ⚡ 50+ 代码片段
  - Button、Input、Select、Textarea
  - Checkbox、RadioGroup、Switch、Slider
  - InputNumber、PasswordInput、DateTimePicker
  - ColorPicker、FileUpload、UploadButton
  - Card、Avatar、Badge、Alert
  - Tabs、Modal、Tooltip
  - Skeleton、Spinner、Icon
  - Form、DataTable、Chart
- 🔧 工具功能
  - 组件库浏览器（侧边栏）
  - 自动导入功能
  - 文档链接跳转
  - 状态栏主题显示
- 🎨 支持的主题
  - Corporate Blue（企业蓝）
  - Corporate Navy Dark（企业深蓝）
  - Minimal White（极简白）
  - Minimal Graphite Dark（极简深灰）
  - Tech Cyan（科技青）
  - Tech Neon Dark（科技霓虹）
  - Creative Purple（创意紫）
  - Creative Aurora Dark（创意极光）
  - Classic Neutral（经典中性）
  - High Contrast Pro（高对比度）

### 技术特性
- 🔥 基于 VS Code Extension API
- 💻 支持 TypeScript、JavaScript、TSX、JSX
- 🚀 高性能缓存机制
- 🎯 智能上下文感知
- 🔍 全文搜索支持
- ⚡ 快速响应（<100ms）

### 支持的组件
- **Inputs** (15个): Button, Input, Select, Textarea, Checkbox, RadioGroup, Switch, Slider, InputNumber, PasswordInput, DateTimePicker, ColorPicker, FileUpload, UploadButton, Autocomplete
- **Data Display** (8个): Card, Avatar, Badge, Table, Code, Kbd, Icon, Progress
- **Navigation** (3个): Tabs, Breadcrumb, Pagination
- **Overlays** (4个): Modal, Tooltip, Popover, Drawer
- **Feedback** (5个): Alert, Skeleton, Spinner, Toast, Progress
- **Media** (3个): Image, Icon, Video
