## 🛡️ Hooks 保护系统 (1个)

### PreToolUse Hook - 命令验证保护

**位置**: `.claude/hooks/validate-bash.py`
**状态**: ✅ 已部署并通过测试
**版本**: 1.0.0

#### 保护目标
- ❌ **严禁使用 `npm run dev` 命令**
- ❌ **严禁直接操作 Docker，必须通过代理系统**
- ❌ **严禁使用端口 3000/3001**
- ✅ **必须使用 Docker 热更新容器 (端口 3100)**
- ✅ **只能通过代理系统管理开发环境和 Docker 操作**

#### 触发机制
```
用户输入命令 → Claude Code 接收 → PreToolUse Hook 触发 → validate-bash.py 验证 → 允许/阻止执行
```

#### 禁止命令模式
```python
forbidden_patterns = [
    r'npm\s+run\s+dev',
    r'npm\s+run\s+dev:website',
    r'yarn\s+dev',
    r'pnpm\s+dev',
    r'npm\s+start',
    r'next\s+dev'
]

forbidden_port_patterns = [
    r'--port\s+3000',
    r'-p\s+3000',
    r':3000',
    r'--port\s+3001',
    r'-p\s+3001',
    r':3001'
]
```

#### 允许命令白名单
```python
allowed_patterns = [
    r'docker-compose.*up',
    r'docker.*run',
    r'npm\s+run\s+docker:dev',
    r'npm\s+run\s+agent:',
    r'\./scripts/agent-dev-server\.sh'
]
```

#### 触发条件示例

**被阻止的命令**:
```bash
npm run dev                    # ❌ 被阻止
yarn dev                       # ❌ 被阻止
npm start -- --port 3000       # ❌ 被阻止
next dev                       # ❌ 被阻止
```

**允许的命令**:
```bash
npm run docker:dev             # ✅ 允许执行
npm run agent:start            # ✅ 允许执行
docker-compose up              # ✅ 允许执行
./scripts/agent-dev-server.sh  # ✅ 允许执行
```
