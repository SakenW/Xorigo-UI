# Xorigo UI 设计系统验证器

这个 Skill 专门用于验证 Xorigo UI 组件是否完全符合设计系统规范和最佳实践。

## 验证范围

### 🔍 设计令牌使用检查
- **颜色规范** - 检查是否使用 `var(--color-*)` 而非硬编码值
- **间距系统** - 验证使用标准间距令牌 (`--spacing-sm/md/lg`)
- **字体系统** - 检查字体大小、行高、字重使用标准令牌
- **圆角系统** - 验证圆角使用 `--radius-*` 令牌
- **阴影系统** - 检查阴影使用 `--shadow-*` 令牌
- **动画系统** - 验证动画使用 `--transition-*` 令牌

### 🎨 主题兼容性验证
- **10 种主题测试** - 验证组件在所有主题下的视觉效果
- **对比度检查** - 确保文本在所有主题下可读性达标
- **颜色一致性** - 检查组件颜色在不同主题下的语义一致性
- **边界情况** - 验证主题切换时的平滑过渡

### 📏 API 一致性检查
- **Props 命名规范** - 验证使用标准的属性命名模式
- **变体系统** - 检查 variant 和 size 属性的标准实现
- **事件处理** - 验证事件处理器的类型和命名规范
- **Ref 转发** - 检查是否正确实现 forwardRef
- **displayName** - 验证组件 displayName 的设置

### ♿ 可访问性标准
- **ARIA 属性** - 检查必需的 ARIA 标签和属性
- **键盘导航** - 验证键盘操作支持
- **焦点管理** - 检查焦点状态和焦点陷阱
- **屏幕阅读器** - 验证屏幕阅读器兼容性
- **颜色对比度** - 检查 WCAG 2.1 AA 级别对比度

### 🏗️ 组件架构验证
- **Atomic Design** - 验证组件的原子化设计原则
- **组合模式** - 检查是否支持组件组合（如 Card + CardHeader）
- **Render Props** - 验证灵活的渲染控制支持
- **Context 集成** - 检查与 ThemeProvider 的集成

## 检查流程

### 1. 静态代码分析
- 解析组件源码
- 检查 Tailwind CSS 类名
- 分析样式变量使用
- 验证 TypeScript 类型定义

### 2. 自动化测试
- 渲染组件到测试环境
- 运行可访问性测试套件
- 执行主题切换测试
- 进行响应式设计验证

### 3. 视觉回归测试
- 截图对比所有主题下的组件外观
- 检查动画效果一致性
- 验证交互状态（hover、focus、disabled）

## 问题分类

### 🚨 严重错误 (Must Fix)
- 硬编码颜色值
- 缺少必需的 ARIA 属性
- 不符合 API 规范
- 主题兼容性问题

### ⚠️ 警告 (Should Fix)
- 设计令牌使用不一致
- 可访问性最佳实践缺失
- 性能优化建议
- 代码风格问题

### 💡 建议 (Nice to Have)
- 组件增强建议
- 文档完善提醒
- 测试覆盖率提升
- 用户体验优化
